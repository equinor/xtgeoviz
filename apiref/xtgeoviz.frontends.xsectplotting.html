xtgeoviz.frontends.xsectplotting module

Making cross sections (plots), primarely wells.

xtgeoviz.frontends.xsectplotting.xsectplot(args=None, inputdata=None, plotsettings=None, output=None, verbosity=None)[source]

Create cross-section plots from YAML configuration or Python mappings.

When inputdata is truthy, the inputdata, plotsettings, and output mappings are merged with defaults. Otherwise, configuration is read from command-line arguments.

Parameters:

  • args (list[str] | None) – Optional command-line tokens to parse. When omitted and dictionary input is not provided, command-line parsing reads sys.argv.

  • inputdata (dict[str, Any] | None) – Input sources such as wells, surfaces, cube, and outline.

  • plotsettings (dict[str, Any] | None) – Overrides for design, colors, ranges, and overlays.

  • output (dict[str, Any] | None) – Output folder, format, PDF, and cleanup settings.

  • verbosity (Optional[str]) – Optional logging level override; otherwise the config value is used.

Return type:

None

Returns:

None.

Raises:

  • OSError – If the selected YAML config file does not exist.

  • ValueError – If a supplied configuration contains invalid keys.

  • SystemExit – If command-line arguments are incomplete or invalid.
